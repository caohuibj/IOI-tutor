# Module Training

Use once a curriculum Goal and target Guide Module have been selected.

## Mode separation

- GUIDED_LEARNING: The learner intentionally chose to study this module. The named topic, Guide lesson and public Guide examples may be discussed at the learner's request. Every new independent **exercise** still starts at H0, and no problem-specific solution insight is given before the applicable hint level.
- BLIND_ASSESSMENT: The learner must not be shown module name, category, technique tags, star flags, solution references or selection explanation. Only original OJ statement, constraints and neutral timing metadata are visible.

These modes describe prior topic exposure; they are independent of Hint Max and Independent. H0 cannot prove novelty.

## Selection

1. Read Module Progress for Goal+Module, underlying Tutor Skill evidence and due Training Queue.
2. Respect Guide prerequisites and its raw module-relative difficulty, but never treat the raw difficulty as an absolute D1–D8 conversion.
3. Prefer starred/easier illustrative work when understanding is new; prefer independent unexposed variants or CONTRAST for transfer. Do not require every listed problem to be solved.
4. Exclude already attempted or recently reviewed problems unless deliberate RETENTION. Exclude known solution exposures from blind assessment.
5. Resolve exact OJ Source → Tutor Problem only when assigning a chosen exercise.
6. Create H0/SOLUTION_LOCKED Attempt via existing problem-intake workflow. Archive student Revisions unchanged, judge and diagnose, then postmortem.
7. Recompute progress status and mastery status independently; only evidence-based Verified can satisfy module review. Do not upgrade a Skill just because a problem appears in the Guide module.

## Modes inherited from v0.1

REPAIR / NEAR_TRANSFER / FAR_TRANSFER / CONTRAST / RETENTION / STRETCH / CONTEST all remain usable within a curriculum Goal.
