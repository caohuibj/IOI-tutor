# Baseline Assessment

Use when a new Gold/Platinum curriculum goal has inadequate independent performance evidence.

1. Read recent real Notion Attempts and judged scores, hint use, duration, previous exposure, Skill Profile and Error Events.
2. Historical graded work is evidence if authentic; never rewrite prior H-level, novelty or exposure history.
3. If independent evidence is sparse, select a small, unseen diagnostic set spanning relevant prerequisites and core skills. Prevent Guide module/category clues from leaking; classify session as BLIND_ASSESSMENT.
4. An unseen problem requires affirmative exposure screening. If prior viewings are unknown, record uncertainty and avoid treating it as certified blind evidence.
5. Use actual judge verdicts and partial subtasks; unaudited code review is UNTESTED, not AC.
6. Infer skill needs conservatively, emphasizing correctness, modeling, complexity and time/score strategy. No data → UNKNOWN; a single success is not mastery.
7. Store Assessment and linked Attempts in Notion when schema exists. Otherwise provide a plan only; never claim persistence.
8. Seed a small Training Queue and Goal stage from the evidence after the diagnostic.

Never use Guide's solution/tags to teach a student during the diagnostic. Internally the Tutor may analyze, but disclosure respects H0.
